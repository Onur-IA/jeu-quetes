# Jeu de quêtes

Une petite appli pour cocher tes quêtes du jour, avec un immeuble qui grandit à mesure que tu avances. Aucun compte. Ta partie reste dans ton navigateur.

## Jouer

Ouvre [la page des quêtes du jour](https://onur-ia.github.io/jeu-quetes/express.html) dans Safari, puis : Partager, « Sur l'écran d'accueil ».

Le matin, dis comment tu te sens. Le jeu te propose les quêtes qui collent. Tu règles les coûts, les objectifs, les niveaux : rien n'est imposé.

Pour garder une copie, utilise Sauvegarde, puis Exporter. Range le fichier où tu veux. L'import remplace la partie de l'appareil ; l'ancienne est mise de côté.

## Données

Le dépôt public ne contient que le jeu, avec quelques quêtes d'exemple. Tes vraies quêtes et tes encaissements ne quittent pas ton appareil.
